# 🎓 LMS Review & Progress Engine

Асинхронный backend-сервис образовательной платформы: сдача практических заданий,
маршрутизация работ по очередям менторов и аналитика успеваемости.

> ⚠️ **Status: In Active Development (WIP)**
> Проект находится в активной разработке. Архитектура, схема базы данных и контракты API
> ещё проектируются и меняются — возможны breaking changes, а часть функциональности
> пока не реализована. README будет дополняться по мере готовности компонентов.

---

## 🎯 Цель проекта

Собрать backend для учебного процесса: приём и проверка практических заданий,
распределение работ между менторами и отслеживание прогресса студентов.

Более подробное описание домена, эндпоинтов и схемы БД появится позже.

## 🛠 Tech Stack

**Язык и окружение**
- **Python** — язык разработки сервиса.
- **uv** — менеджер пакетов и виртуальных окружений: быстрая установка интерпретатора
  и разрешение зависимостей строго по lock-файлу.

**Веб-слой**
- **FastAPI** — асинхронный веб-фреймворк для построения HTTP API.

**Данные**
- **PostgreSQL** — основная реляционная база данных.
- **SQLAlchemy** — ORM и работа с запросами, включая сложные выборки для аналитики.
- **Alembic** — миграции схемы базы данных.

**Сообщения и фоновые задачи**
- **Apache Kafka** — брокер сообщений для фоновой обработки.
- **FastStream** — фреймворк для потребителей сообщений и воркеров.

**Качество кода и CI**
- **Ruff** — линтинг и форматирование.
- **Mypy** — статическая типизация в strict-режиме.
- **Pytest** — тестирование.
- **GitHub Actions** — CI-пайплайн.
